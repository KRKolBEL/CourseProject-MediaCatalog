## 📝 Описание проекта
**MediaCatalog** — это десктопное приложение для учета домашней медиатеки. Программа позволяет систематизировать информацию о фильмах, книгах и играх, отслеживать статус их просмотра/прочтения/прохождения, а также выставлять оценки.

Приложение разработано с использованием методологии **Agile** (итерационная разработка с ведением истории коммитов).

## 🚀 Основные возможности
*   **Добавление записей:** Фильмы, Книги, Игры.
*   **Поиск:** Быстрый поиск по названию и жанру.
*   **Валидация данных:** Защита от неверного ввода (например, проверка года и оценки через регулярные выражения).
*   **Сохранение данных:** Автоматическое сохранение медиатеки в локальный файл формата JSON.
*   **Журналирование:** Запись всех действий и ошибок в лог-файл.

## 🛠️ Используемый стек технологий
*   **Язык программирования:** C# (.NET 8)
*   **Интерфейс:** WPF (Windows Presentation Foundation)
*   **Архитектура:** Разделение на слои (Core / WPF / Tests), паттерн Repository.
*   **Сериализация:** `System.Text.Json`
*   **Логирование:** `Serilog` (с сохранением в файл)
*   **Тестирование:** `xUnit`
*   **Контроль версий:** Git, GitHub

## 📂 Структура решения
*   `MediaCatalog.Core` — библиотека классов (модели данных, бизнес-логика, репозиторий).
*   `MediaCatalog.WPF` — графический интерфейс пользователя.
*   `MediaCatalog.Tests` — модульные (Unit) тесты.
